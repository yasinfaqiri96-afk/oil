# جدول تفاوت‌های PTG با چرتکه و برنامه هم‌ترازی

مرجع اعداد چرتکه: [`docs/chortke-design-analysis.md`](./chortke-design-analysis.md).
مرجع اعداد PTG: `wwwroot/css/ptg/01-tokens.css`، `06-forms.css`، `07-tables.css`، `03-layout.css`.

## خلاصه وضعیت

پالت رنگ PTG قبلاً تا حد زیادی روی چرتکه تنظیم شده است (`#1062D0`، `#F5F6FA`،
`#F2F5FC`، `#CB0B0B`، `#24AF22`، `#AEAEAE`، `--ptg-label: #4F4F4F`). تفاوت‌های
باقی‌مانده عمدتاً در **مقیاس تایپ، چگالی جدول، شعاع‌ها، متریک شل و منوی کناری** است.

## C) مواردی که PTG از قبل مطابق است (دست نخورد)

- رنگ اصلی `#1062D0`، پس‌زمینه `#F5F6FA`، سطح نرم `#F2F5FC`
- خطر `#CB0B0B`، موفقیت `#24AF22`، غیرفعال `#AEAEAE`
- `--shadow-card: none` (کارت تخت)
- ارتفاع کنترل فرم `40px`، شعاع کنترل `6px`
- خانواده فونت (`IRANSans` که همان IRANSansFaNum است)
- نبود خط عمودی در جدول‌ها

## D) ترتیب اجرای پیشنهادی

1. **گام ۱ — توکن‌ها** (`01-tokens.css`): مقیاس تایپ، شعاع‌ها، متریک هدر. کم‌ریسک، اثر سراسری.
2. **گام ۲ — جدول** (`07-tables.css`): چگالی، رنگ/وزن هدر، sticky، hover.
3. **گام ۳ — فرم** (`06-forms.css`): لیبل، شعاع کارت، حالت فیلد پرشده.
4. **گام ۴ — شل** (`03-layout.css` / `04-sidebar.css`): ارتفاع هدر، سپس تصمیم درباره منوی کناری.
5. **گام ۵ — الگوهای ساختاری** (بند B): هرکدام یک تغییر مستقل و قابل بازگشت.

> گام ۴ (منوی سرمه‌ای → ریل سفید) بزرگ‌ترین تغییر هویتی است و باید جداگانه تأیید شود؛
> بقیه گام‌ها فقط CSS هستند و منطق/کنترلر/روت را لمس نمی‌کنند.

## F) دامنه واقعی تغییر — چه فایل‌هایی، چند ویو

مخزن ۳۹۶ فایل `.cshtml` دارد، ولی واژگان کامپوننت مشترک است (`ak-field` ۱۲۱۸ بار،
`ak-input` ۱۲۰۷، `ak-label` ۹۲۹، `ak-table` ۲۸۵، `ak-status` ۲۴۰، `ak-empty` ۱۶۳).
بنابراین تغییر در **لایه‌های CSS + چند پارشال مشترک** انجام می‌شود، نه در ۳۹۶ ویو.
