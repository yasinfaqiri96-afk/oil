# تحلیل پیکسلی طراحی نرم‌افزار حسابداری چرتکه (panel.chortke.app)

روش استخراج: اتصال Playwright به مرورگر واقعی روی نسخه دمو، خواندن `getComputedStyle`
از عناصر زنده + دانلود باندل CSS (`/assets/index-0eVO0AXX.css`، ۴۲۹ کیلوبایت) و شمارش
فراوانی رنگ/شعاع/سایه. viewport مرجع: 1600×950، DPR 1، `dir=rtl`.

## ۰) استک فنی مرجع

| مورد | چرتکه |
|---|---|
| فریم‌ورک UI | React + MUI v5 (کلاس‌های `Mui*` و `css-*` از Emotion) |
| Utility CSS | Tailwind (`bg-[#f4f4f4]`، `rounded-[10px]`، `text-sm`) |
| CSS variables | ندارد — رنگ‌ها هاردکد hex (فقط `--swiper-*` موجود است) |
| جهت | `dir="rtl"` |
| فونت | `IRANSansFaNum` + وزن‌های `_Light` / `_Bold` / `_Black` |

> PTG نباید React/MUI/Tailwind بگیرد (ممنوعیت صریح در `CLAUDE.md`).
> هدف، بازتولید **نتیجه بصری** با Razor + Bootstrap RTL و لایه‌های CSS موجود است.

## ۶) جدول (`.data-table`) — قوانین خام از CSS چرتکه

```css
.data-table            { border-collapse: collapse; width: 100%; overflow-x: auto; border-radius: 12px }
.data-table thead      { background: #f2f5fc }
.data-table thead th   { position: sticky; top: 0; z-index: 8; background: #f2f5fc;
                         box-shadow: inset 0 -1px #e8e8e8 }
.data-table th         { white-space: nowrap; padding: 5px 10px; background: #f2f5fc; color: #7e8c9e }
.data-table td         { white-space: nowrap; padding: 5px 10px }
.data-table .item-data-table       { height: 45px; background: #fff; border-bottom: 1px solid #e8e8e8 }
.data-table .item-data-table:hover { background: #f7f9fd }
.data-table .fixed-column          { position: sticky !important; left: 0; top: 0; padding: 0 }
```

اندازه‌های اندازه‌گیری‌شده در «همه فاکتورها»:

- ارتفاع `thead` = `52.5px`؛ ارتفاع ردیف داده = `45.5px` تا `52.5px`
- `th`: وزن `700`، رنگ `#7E8C9E`، اندازه `14px`
- **هیچ خط عمودی بین ستون‌ها نیست** — فقط جداکننده افقی `1px #E8E8E8`
- ستون checkbox با عرض ثابت `90px`
- ۱۷ ستون در یک جدول با اسکرول افقی و ستون چسبان
- ردیف دوم هدر = ردیف «فیلتر و جستجو» با ذره‌بین در هر ستون
- آیکون مرتب‌سازی کنار هر عنوان
- منوی سه‌نقطه عمودی در انتهای ردیف
- صفحه‌بندی **بالای** جدول، نه پایین
- نوار ابزار: انتخاب تعداد ردیف + «صفحه ۱ - ۲۳ (نتیجه ۴۴۴)» + دکمه دانلود
- انتخابگر ستون‌ها → popover با toggle و دستگیره جابه‌جایی

## ۷) فرم — آناتومی دقیق

| عنصر | مقدار |
|---|---|
| کارت بخش فرم | `bg #FFF`، `border-radius: 10px`، بدون سایه، بدون بوردر |
| ارتفاع کنترل | **`40px`** |
| شعاع کنترل | `6px` |
| بوردر کنترل | `1px solid #CBD5E1` |
| پس‌زمینه کنترل | `#F2F5FC` (پرشده/فقط‌خواندنی) یا سفید |
| padding افقی | `12px` |
| لیبل | بالای فیلد، `14px/20px`، `#2B2B2B`، `gap: 4px` با ستاره الزامی قرمز |
| textarea | `padding: 8px`، `border: 1px solid #C8C8C8`، `radius: 6px` |
| chip فرم باز | `bg #F4F4F4`، `radius: 8px`، `padding: 4px 8px`، `height: 44px` |
| select درون‌خطی | زیرخط نقطه‌چین (انبار، قیمت فروش، ارز) |
| «فیلدهای بیشتر» | chevron دایره‌ای، پیش‌فرض بسته |

الگوهای ساختاری فرم فاکتور:

1. نوار «فرم‌های باز» در بالای صفحه — چند سند هم‌زمان با ضربدر بستن
2. کارت ۱ = هدر سند (نوع فاکتور به شکل segmented control، تاریخ، طرف حساب)
3. کارت ۲ = اقلام، جدول ورودی با ردیف‌های input و ضربدر حذف
4. کنش‌های پرکاربرد به شکل لینک آبی درون‌خطی («افزودن سریع کالا»، «مشاهده تراز»)

## ۱۰) صفحه گزارش‌ها (Hub)

- عنوان و زیرعنوان **راست‌چین**، نوار تب دسته‌بندی **وسط‌چین**
- عنوان دسته (مالی، حسابداری) به‌عنوان تیتر بخش
- گرید ۲ ستونه از کارت‌های گزارش
- هر کارت: آیکون دایره‌ای رنگی سمت راست + عنوان وسط + ستاره علاقه‌مندی سمت چپ
- ارتفاع کارت ~`96px`، فاصله بین کارت‌ها ~`24px`
- فضای خالی زیاد؛ حداکثر ۲ کارت در عرض

## ۱۱) صفحه گزارش (تراز آزمایشی)

- سربرگ: عنوان راست + لینک «بازگشت» چپ
- ناحیه فیلتر: select های outlined با لیبل شناور، چک‌باکس گروهی، فیلد تاریخ با آیکون
- انتخاب سطح حساب: ردیف دکمه‌های آبی پرشده با آیکون
- جدول گزارش: هدر `#F5F8FF`، بدون بوردر عمودی
- **بدهکار قرمز `#CB0B0B` / بستانکار سبز `#24AF22`**
- ردیف «جمع کل» چسبان در انتها با پس‌زمینه روشن
- «دانلود اکسل» به شکل آیکون سبز + متن، نه دکمه

## ۱۲) حالت خالی

متن خاکستری وسط‌چین + آیکون info دایره‌ای: «داده ای برای نمایش وجود ندارد!»
بدون تصویر بزرگ و بدون کارت اضافه.

## ۱۳) ده اصلی که «حس آرامش» چرتکه را می‌سازد

1. **یک رنگ لهجه** (`#1062D0`) و بس؛ رنگ دیگر فقط برای وضعیت
2. **زمینه بسیار روشن `#F5F6FA` + کارت سفید بدون سایه** — عمق تقریباً صفر
3. **بدون بوردر عمودی در جداول**؛ فقط خط افقی `#E8E8E8`
4. **مقیاس تایپ سه‌تایی (۲۴/۱۶/۱۴)** و نه بیشتر
5. **هدر جدول کم‌کنتراست** (`#7E8C9E` روی `#F2F5FC`) تا داده جلو بیفتد
6. **ریل آیکونی باریک ۷۰px سفید** — منو فضای صفحه را نمی‌خورد
7. **فضای خالی سخاوتمندانه** بین بخش‌ها
8. **کنش ثانویه به شکل لینک آبی، نه دکمه** — دکمه پررنگ در هر صفحه حداکثر یکی
9. **ردیف جدول کوتاه (۴۵px) با padding کم (`5px 10px`)** — چگالی بالا بدون شلوغی
10. **پیشرفته‌سازی تدریجی**: «فیلدهای بیشتر» و انتخابگر ستون، پیش‌فرض بسته
